# Context Stack Index

This is the starting point for the PM context stack.

## Common Starts

| Need | Read first |
| --- | --- |
| Review or maintain the wiki | [[wiki-system]], [[workflows/weekly-review]], then recent relevant [[log]] entries |
| Current priorities or planning cycle | [[okrs]] and [[roadmap]], then their checked sources |
| Decisions and dependencies | [[decision-log]] and the specific decision or assumption |
| Stakeholder communication | [[stakeholder-map]] and [[workflows/stakeholder-update]] |

Read bounded relevant sections first. Index entries route to evidence; they do
not establish that a claim is current.
