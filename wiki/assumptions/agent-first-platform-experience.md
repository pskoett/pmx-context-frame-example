# Assumption: Agent-First Platform Experience

## Assumption

If platform setup instructions, requirements, and examples are agent-readable, then developers using coding agents can deploy compliant internal apps with less direct platform support.

## Why It Matters

This assumption connects the DX adoption goal to the Platform validation goal. If it is false, the combined bet weakens and the streams may need separate plans.

## Evidence We Have

- Developers are already using agents to create small internal tools.
- Platform setup has repeated friction points that can be documented and tested.
- The deployment path requires structured metadata that agents can help collect.

## Evidence We Need

- Whether agents can follow the setup path without missing required metadata.
- Whether developers understand the boundary between prototype and production.
- Whether support requests decrease as the agent-readable guide improves.

## Test

Run 5 to 10 pilot apps through the guided path and record every point where the developer or agent needs human intervention.

Open.
