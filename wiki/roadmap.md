# Roadmap

## Now

- Define the vibe-coded app workload class.
- Identify first pilot users from DX training cohorts.
- Map current self-service deployment requirements.
- Convert setup guidance into agent-readable markdown.
- Open the validation cluster decision for stakeholder review.

## Next

- Run the first pilot with 5 to 10 internal apps.
- Measure where developers or agents need human platform support.
- Patch the golden path based on real failure modes.
- Publish a stakeholder update comparing AI adoption outcomes and platform validation outcomes.

## Later

- Expand from prototypes to team-owned internal tools.
- Decide whether the agent-first path should become the default platform onboarding path.
- Reuse the validated flow for a production workload class.

## Watchlist

- Security requirements may make the pilot slower than expected.
- Platform ownership metadata may be incomplete for prototype apps.
- DX may optimize for adoption volume while Platform optimizes for reliability evidence.
